# OntOS context map

This file is a selector, not a glossary. Read only the context needed for the current decision.

| Context                                       | Read when the task concerns                                                                                |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [OntOS](docs/contexts/ontos/CONTEXT.md)       | Core, modules, identity, shared business vocabulary, integrations, deployment, or evidence                 |
| [Projects](docs/contexts/projects/CONTEXT.md) | Tasks, collections, properties, views, access, search, sorting, or change history                          |
| [Commerce](docs/contexts/commerce/CONTEXT.md) | B2C/B2B channels, catalog, customers, ordering, payments, fulfillment, storefronts, or commerce operations |

Contexts define language only. Accepted decisions live in [ADRs](docs/adr/README.md), while current
implementation rules live under [`app/docs/`](app/docs/). If a term is unsettled, keep it in the
relevant GitHub issue until it is agreed; do not present it here as established vocabulary.
