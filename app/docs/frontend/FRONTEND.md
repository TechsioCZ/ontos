# Frontend Rules

Follow these rules for every task that affects the user-facing frontend (FE):

- Always use components from the [UI Kit](https://github.com/TechsioCZ/new-engine).
- Never write plain CSS. Always use the installed version of Tailwind CSS.
- Do not invent new components. Reuse components as much as possible, preferably by composing existing components from the UI Kit upward. If you need a new component, raise the requirement and wait for a developer to confirm it before proceeding.
- When writing React components, follow [React Architecture Rules](./REACT.md).
