# Installed packages the app runtime tree leaves out (scripts/zerops/pack-app-release.sh; the same tree is proven by
# scripts/zerops/prove-app-runtime.mts and assembled by scripts/prove-zerops-migrator-artifact.sh).
#
# One npm package name per line; `*` stands for any characters within the last name segment (platform builds).
# An entry is admissible only when nothing the runtime runs can load it:
# - no package that stays depends on it (pnpm-lock.yaml; the proof checks every installed link after the exclusion),
# - a workspace package names it only as a devDependency, and
# - no code the app host, the migrator or a unit entry reaches imports it (the proof walks and imports them).
# All of these run only at install, build, lint, format, test or code-generation time. None is `next`, `typescript`,
# `drizzle-kit`, `esbuild` or a build framework the unit entries import: those have runtime dependents and stay.
